# Support

Use [GitHub Issues](https://github.com/kennywillbe/vscode-mcp/issues) for reproducible
bugs and feature requests. Consult the installation and agent-usage guides before filing
a setup issue.

Do not disclose a suspected vulnerability in an issue, discussion, Marketplace review,
or other public channel. Follow [SECURITY.md](./SECURITY.md) instead.

Support covers the documented macOS/Linux local VS Code Desktop matrix. Windows, remote,
web, virtual, and sandboxed workspaces are not supported by version 1.0.
