# Full 1.0 IDE security acceptance criteria

- Status: Accepted; implementation evidence recorded in
  `security-acceptance-report-v1.0-full-ide.md`
- Scope: complete tool contract `1.0.0`

| ID         | Boundary             | Given                                                                                                           | When                                                                | Then                                                                                                                                                     |
| ---------- | -------------------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1-GRT-001 | Extension Host       | Read is enabled and write/exec are initially off                                                                | status and high-impact tools run                                    | Status is visible; writes return `WRITE_NOT_ENABLED`; starts return `EXECUTION_NOT_ENABLED`; no side effect occurs.                                      |
| F1-GRT-002 | Extension Host       | User enables and revokes each grant                                                                             | calls race the transitions                                          | Only the current generation commits/starts; previews and queued work from older generations fail.                                                        |
| F1-GRT-003 | Lifecycle            | Trust/read/workspace identity is lost                                                                           | work is queued, preparing, committed, or running                    | Pre-commit/start work stops; cursor/preview handles die; tracked execution is terminated; post-commit reality is not mislabeled rollback.                |
| F1-EDT-001 | Unit/Host            | 1–32 documents contain sorted valid edits                                                                       | apply runs                                                          | One text-only workspace edit applies, versions and dirty states are reported, replacement/source text is absent.                                         |
| F1-EDT-002 | Unit                 | Edits overlap, exceed limits, use malformed ranges, stale versions, another root, symlinks, or unsupported URIs | validation runs                                                     | Entire plan fails before commit and no sibling changes.                                                                                                  |
| F1-EDT-003 | Race Host            | Cancellation/revocation/version change occurs before and after commit begins                                    | apply runs                                                          | Before commit no edit; after commit response reports observed outcome without rollback claim.                                                            |
| F1-FIL-001 | Host                 | Destination is absent with canonical existing parents                                                           | create runs                                                         | One non-overwriting regular file is created with exact bounded bytes.                                                                                    |
| F1-FIL-002 | Host                 | Destination exists, parent missing/symlinked/external, or directory operation requested                         | create/move/delete runs                                             | Stable safe error and no filesystem change.                                                                                                              |
| F1-FIL-003 | Host                 | Existing regular file and absent same-root destination                                                          | move/delete runs                                                    | Exactly the requested resource operation occurs; overwrite/recursive behavior is impossible.                                                             |
| F1-PRV-001 | Provider unit        | Rename/format/code action returns bounded text-only edits                                                       | validation and apply run                                            | Every edit is authorized and applied through the common no-yield commit path.                                                                            |
| F1-PRV-002 | Provider unit        | Result includes command, external URI, resource edit, snippet/opaque edit, cycle, overlap, or overflow          | validation runs                                                     | `OPAQUE_PROVIDER_EDIT` or stable bound error; provider command is never executed.                                                                        |
| F1-PRV-003 | Unit/Host            | Code-action preview token is reused, expired, tampered, cross-grant, cross-document, or cross-listener          | apply runs                                                          | Token fails closed and no edit occurs; valid token is single-use.                                                                                        |
| F1-LSP-001 | Provider unit        | Each additional provider returns malformed, huge, cyclic, external, stale, or mixed results                     | read tool runs                                                      | Strict bounded projection, authorized locations only, deterministic order, explicit truncation.                                                          |
| F1-TSK-001 | Host                 | 0, 1, 200, 201 and ambiguous tasks are discovered                                                               | list runs                                                           | Only scoped safe metadata is returned; commands/args/env/paths are absent; caps are explicit.                                                            |
| F1-TSK-002 | Host                 | Valid opaque task ID and execution grant exist                                                                  | run/poll/terminate run                                              | Exact rediscovered task starts; only its tracked ID is controllable; exit and diagnostics are bounded.                                                   |
| F1-TSK-003 | Host                 | ID is forged/stale/cross-listener, task becomes ambiguous, grant changes, or task cap is full                   | run runs                                                            | Start fails before `executeTask`; no alternate task is selected.                                                                                         |
| F1-TSK-004 | Scheduler            | Tasks finish, hang, reject, revoke, disconnect, or race termination                                             | tracking runs                                                       | Slots release exactly once; lifetime cap terminates; late events cannot resurrect state.                                                                 |
| F1-DBG-001 | Host                 | Named configuration and execution grant exist                                                                   | debug/no-debug starts                                               | Only the folder-scoped name is submitted; session is correlated and bounded.                                                                             |
| F1-DBG-002 | Host                 | Arbitrary config/DAP input, stale ID, foreign session, or revoked grant is supplied                             | debug controls run                                                  | Input/schema rejects or stable not-found; no custom request/evaluation occurs.                                                                           |
| F1-OUT-001 | Output unit          | Maximum write/provider/task/debug results are built                                                             | serialization runs                                                  | Success remains below 448 KiB target and global 512 KiB; no content or secret duplication.                                                               |
| F1-LOG-001 | Instrumentation      | Canaries occupy every sensitive field                                                                           | success/failure/cancel/revoke/log paths run                         | Logs and persisted state contain no canary; only approved aggregate metadata exists.                                                                     |
| F1-CMP-001 | Process/static       | Complete 39-tool build is inspected                                                                             | tests run                                                           | No generic shell, terminal input, Git, arbitrary command, DAP custom request, HTTP listener, telemetry, overwrite, or recursive deletion surface exists. |
| F1-E2E-001 | Packaged macOS/Linux | Exact VSIX/server pair is freshly installed                                                                     | representative explore-edit-create-rename-build-debug workflow runs | All capability/grant transitions and results match contract with no host filesystem fallback needed for ordinary work.                                   |

Every row requires repeatable automated evidence before the release candidate can close.
